## TecaBiblio

## Ideia do projeto

O sistema permitirá cadastrar e consultar livros, autores e usuários, além de controlar empréstimos e devoluções.

## Funcionalidades planejadas

- Cadastro, consulta, atualização e remoção de livros.
- Cadastro e consulta de autores.
- Cadastro e consulta de usuários.
- Registro de empréstimos e devoluções.

## Objetivo

Desenvolver uma API para facilitar o gerenciamento de uma biblioteca, permitindo organizar seu acervo e controlar a movimentação dos livros.

## Tecnologias utilizadas

- Python 3.14
- FastAPI
- Poetry
- Pytest
- Ruff
- HTTPX

## Execução do projeto

- poetry install
- poetry run uvicorn app:app --reload

http://127.0.0.1:8000/docs

## Como executar os testes

poetry run pytest
